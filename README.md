## 👨‍💻 About me

- 🏢 Full-stack developer in **São Paulo, Brazil**, building internal platforms that connect **ERP (TOTVS Protheus)**, web apps, AI agents and desktop tools.
- 🧩 Creator of **[Mufox](https://mufox.space)**, a platform with an API middleware engine, project hub, coding tracker and desktop launcher.
- 🤖 Building **AI agents with Claude** that study company documents, answer the team in chat and analyse public tenders.
- ⚙️ From **STM32 firmware and PCBs** to **React, Laravel and Rust**, I like owning the whole stack.
- 🔒 Most of my work lives in **private repositories**; the highlights are summarised below.

## 🔭 What I'm working on

- 🔀 Evolving the middleware engine (Laravel) that powers every internal integration
- 🤖 Teaching AI agents to learn from documentation and keep their knowledge consistent
- 🦀 Shipping Rust desktop apps for Windows (launcher, code editor, API client)
- 🧪 Learning more about LLM training, embedded systems and hardware design
